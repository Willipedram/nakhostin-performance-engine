# NPE administration interfaces

Read [the NPE design system](docs/UI-DESIGN-SYSTEM.md) before changing any administration view, stylesheet, script, or menu registration. Use the shared AdminShell registration and existing components for every new page. Extend the central tokens and components when needed. Keep styles scoped to the NPE admin root, preserve WordPress permissions and form contracts, and validate keyboard use, responsive layouts, Persian RTL and English LTR. Run the administration tests and document any checks the environment cannot support.
